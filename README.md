# Birthday World ✦

Responsive birthday microsite starter built with React and Vite.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Starter sections
- Cinematic birthday intro
- Interactive cake candle and slice states
- Magazine-style page navigation
- Gift reveal interaction

This first version uses CSS illustrations for quick deployment. Next, we can refine the magazine against the reference video and upgrade selected elements to true 3D.
